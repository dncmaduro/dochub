# Docs Hub frontend i18n

The web app supports English (`en`) and Vietnamese (`vi`). Translation resources live in `apps/web/src/i18n/locales/`, with i18next configuration in `apps/web/src/i18n/index.ts`.

Use semantic translation keys through i18next (`translate("files.upload")` in module-level helpers or `useTranslation()` in a component). Add the key to `en.ts` first, then add the Vietnamese value to `vi.ts`. To add another locale, add its resource, register it in `i18n/index.ts`, and extend `Locale` and `resolveLocale`.

The app resolves language from `dochub.language`, then the browser language, and finally English. Changing the language persists it in local storage and updates the document `lang` attribute immediately.
